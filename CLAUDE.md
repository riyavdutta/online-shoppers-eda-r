# Project rules

This repository is a small public portfolio project: an exploratory analysis and logistic regression of the UCI Online Shoppers Purchasing Intention Dataset, written in R to support PhD applications in HCI and consumer behaviour.

Dataset citation: Sakar, C. and Kastro, Y. (2018). Online Shoppers Purchasing Intention Dataset. UCI Machine Learning Repository. CC BY 4.0. https://doi.org/10.24432/C5F88Q

The raw data live in `data/raw/`.

## Rules for the whole project

1. The owner is not a strong coder and must be able to explain every line. Work in small steps, explain each step in plain language, and stop after each step for approval.
2. Use R with tidyverse, broom, car, rmarkdown and knitr.
3. Never use em dashes in any text written for this project.
4. The data are observational, so make no causal claims.
5. Cite the dataset in the README and in the report.
6. Commit only after the owner approves a step, with a clear commit message.
